## 1. 目标

把 B3 已同事务写入 `system.outbox_events` 的业务事件真正发布到 Kafka；实现三段式（claim 短事务 → 事务外发送 → ack/失败短事务）；启动一个审计 consumer 以 `event_id` 幂等消费，验证真实消费链路。

## 3. 三段式

1. **领取段（短事务）**：`OutboxRepo.Claim`（`FOR UPDATE SKIP LOCKED` + `claim_owner/claim_until`）。
2. **发送段（无事务）**：`EventSender.Send`（deadline = claimLease/2）。
3. **标记段（短事务）**：成功 `MarkPublished`；失败 `MarkFailed`（`publish_attempts+1`、`next_retry_at`、清 claim）。
4. 审计 consumer：`consumer='system.audit.v1'`，`event_id` 幂等（`consumer_idempotency`），业务副作用为空（仅写幂等记录）。
