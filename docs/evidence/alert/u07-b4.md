## 3. 冒烟（真实 PG + 真实二进制）

- `POST /services`（含目标）→ 201，`target_count:1`
- `GET /services/:id/targets` → 200 `{targets:[...]}`
- `PATCH /targets/:id` → 200（`target_name` 更新）
- `DELETE /targets/:id` → 204
- `GET /episodes` → 200 `{"total":0,"limit":20,...}`；`?limit=0` / `?status=BAD` → 400
- `GET /services/:id/timeline` → 200 `{records:[]}`
- `POST /services/:id/events` 新事件 → 201（`event_record_id` 从库读回）；同键同内容 → 200；不同内容 → 409 `EVENT_ID_CONFLICT`
- `GET /episodes/nonexistent` / `/timeline` → 404
- 未施工 `/episodes/x/artifacts` → 501
